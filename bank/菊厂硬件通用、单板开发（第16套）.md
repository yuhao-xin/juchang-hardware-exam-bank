# 菊厂硬件通用、单板开发（第16套）

> 来源：菊厂校招/实习 硬件通用、单板开发真题（审核重建稿）

### Q1. 如下不属于电感器件主要规格有
- **A.** 自谐振频率
- **B.** 电感量
- **C.** 品质因数
- **D.** 耐压
- **答案**：D
- **解析**：电感主要规格包括电感量、公差、Q 值、DCR、额定电流、自谐振频率（SRF）等；"耐压"是电容类器件的规格（电感一般不标注耐压）。
- **标签**：元器件｜电源设计

### Q2. I2C 总线结束时(stop)，时钟、数据的状态分别是什么
- **A.** 时钟为低，数据从低电平向高电平跳变
- **B.** 时钟为低，数据从高电平到低电平跳变
- **C.** 时钟为高，数据从高电平到低电平跳变
- **D.** 时钟为高，数据从低电平向高电平跳变
- **答案**：D
- **解析**：I2C 停止条件：SCL 为高电平期间，SDA 由低向高跳变；起始条件则相反（SCL 高时 SDA 由高到低）。
- **标签**：总线协议

### Q3. 3.3V LVTTL 的电平关系
- **A.** VOH>=2.4V; VOL<=0.4V; VIH>=2V; VIL<=0.8V
- **B.** VOH>=2.0V; VOL<=0.2V; VIH>=1.7V; VIL<=0.7V
- **C.** VIH>=2.4V; VIL<=0.4V; VOH>=2V; VOL<=0.8V
- **D.** VIH>=2.0V; VIL<=0.2V; VOH>=1.7V; VOL<=0.7V
- **答案**：A
- **解析**：3.3V LVTTL 沿用 TTL 电平定义：VOH≥2.4V、VOL≤0.4V、VIH≥2.0V、VIL≤0.8V；B/D 是 2.5V LVTTL 的电平。
- **标签**：数字电路｜信号完整性

### Q4. 共模电感的主要作用是
- **A.** 抑制电流尖峰
- **B.** 起高阻作用，抑制差模干扰
- **C.** 起储能作用，通过磁能释放提升电压
- **D.** 起高阻作用，抑制共模干扰
- **答案**：D
- **解析**：共模电感两绕组同向绕制，对共模噪声（同相位）呈高阻抗加以抑制，对差模信号磁通互相抵消、阻抗很小，故主要用于抑制共模干扰。
- **标签**：EMC电磁兼容｜电源设计

### Q5. 可靠性浴盆曲线解读，以下不属于失效率随使用时间的变化阶段的是
- **A.** 随机失效期
- **B.** 试验失效期
- **C.** 耗损失效期
- **D.** 早期失效期
- **答案**：B
- **解析**：浴盆曲线三阶段为早期失效期、偶然（随机）失效期、耗损失效期；"试验失效期"不是浴盆曲线阶段。
- **标签**：其他

### Q6. 主存储器和 CPU 之间增加 Cache 的目的是
- **A.** 解决 CPU 和主存之间的速度匹配问题
- **B.** 扩大 CPU 中通用寄存器的数量
- **C.** 扩大主存储器的容量
- **D.** 既扩大主存容量又扩大 CPU 通用寄存器数量
- **答案**：A
- **解析**：Cache 利用程序局部性原理缓存热点数据，弥补 CPU 与主存的速度差距，解决速度匹配问题；不扩大主存容量，也不属于通用寄存器。
- **标签**：其他｜数字电路

### Q7. 【多选】以下关于电子器件失效浴盆曲线的描述，正确的是()
- **A.** 早期失效可以通过筛选试验避免
- **B.** 早期失效主要由缺陷和设计错误引起
- **C.** 偶然失效期中失效率急剧增加
- **D.** 损耗失效发生在产品生命周期使用期间，失效率低且稳定
- **答案**：AB
- **解析**：早期失效源于工艺缺陷、设计错误，可通过老化筛选剔除（A、B 对）；偶然失效期失效率低且恒定（C 错）；耗损失效期失效率随老化急剧上升（D 错，"低且稳定"是偶然期的特征）。
- **标签**：其他

### Q8. 在频率升高时，普通电容的表现是
- **A.** 阻抗变小，仍然可以看做是电容
- **B.** 阻抗不变，仍然可以看做是电容
- **C.** 不确定
- **D.** 阻抗变小，在越过谐振点后，阻抗变大，表现为感性
- **答案**：D
- **解析**：实际电容存在 ESR/ESL：低频呈容性、阻抗随频率降低，到达自谐振点时阻抗最小（等于 ESR），越过谐振点后 ESL 主导、阻抗随频率增大而增大，呈感性。
- **标签**：元器件｜电源设计

### Q9. 该运放电路是
- **A.** 减法器
- **B.** 加法器
- **C.** 同向放大器
- **D.** 反向放大器
- **答案**：A
- **解析**：原图为典型差分（减法）放大电路：反相端经 R1 接输入 V1、R2 反馈，同相端经 R3/R4 分压接 V2，输出正比于两输入之差，即减法器。
- **标签**：模拟电路

### Q10. 需要测试 156.25MHz 差分时钟信号，Rise/Fall Time(20%~80%)<100ps，请问需要多高带宽的示波器才能精确测量?
- **A.** 10GB
- **B.** 5GB
- **C.** 1GB
- **D.** 2GB
- **答案**：B
- **解析**：边沿 100ps(20%~80%) 对应信号带宽 BW≈0.4~0.5/tr≈4~5GHz；示波器带宽需留裕量并满足时钟频率的 3~5 倍原则，选项中最接近的是 5GHz，选 B。
- **标签**：测试测量｜高频射频

### Q11. 固定网络 TDM 同步需要满足如下哪个条件()
- **A.** 频率同步
- **B.** 时间与频率同步
- **C.** 时钟同步
- **D.** 没有特定要求
- **答案**：B
- **解析**：TDM（时分复用）网络要求全网频率同步以保证时隙对齐，同时要求时间同步以对齐帧/业务，即时间与频率同步都需满足。
- **标签**：其他｜测试测量

### Q12. 以下电路中可以实现"线与"功能的有（此题存疑）
- **A.** 三态输出门
- **B.** 基极开路门
- **C.** 集电极开路门
- **D.** 与非门
- **答案**：C
- **解析**：标准数字电路结论：只有集电极开路（OC）/漏极开路（OD）门在输出端并联（共用上拉）时能实现线与；推挽输出的普通与非门不允许输出并联，三态门用于总线复用而非线与。"基极开路门"并非标准线与实现，本题按标准答案选 C，存疑。
- **标签**：数字电路

### Q13. 下面哪个时钟参数没有处理好会直接影响 Serdes 眼图宽度
- **A.** Skew
- **B.** 抖动
- **C.** 频率准确度
- **D.** 时钟周期
- **答案**：B
- **解析**：抖动（Jitter）直接在时间轴上压缩眼图的横向开口（眼宽），是影响 Serdes 眼图裕量的关键时钟指标；skew 影响采样相对位置，频率准确度、时钟周期一般不直接决定眼图宽度。
- **标签**：信号完整性｜高频射频

### Q14. 在 3.3V TTL 和 CMOS 电路设计中，需要保证合格的噪声容限，即 Vohmin-Vihmin 和 Vilmax-Volmax 应大于或等于
- **A.** 0.4V
- **B.** 1.0V
- **C.** 0.2V
- **D.** 0V
- **答案**：A
- **解析**：3.3V TTL/LVCMOS 高低电平噪声容限典型值约 0.4V（如 VOH2.4-VIH2.0=0.4V，VIL0.8-VOL0.4=0.4V），设计要求噪声容限≥0.4V 以保证可靠。
- **标签**：数字电路｜信号完整性

### Q15. 在多核处理器中，核（Core）是指

### Q16. 如下哪个部件不是锁相环电路基本组成结构
- **A.** 压控振荡器

### Q17. PN 结加正向电压时，空间电荷区宽度将
- **A.** 以上都不对

- **C.** 变窄
- **D.** 变宽
- **答案**：C

### Q18. Pipeline ADC 的特点，描述错误的是
- **A.** 采样率高
- **B.** 分辨率中等
- **C.** 精度低
- **D.** 功耗高
- **答案**：C

- **标签**：测试测量｜模拟电路

### Q19. 某 10bit 的 AD 转换芯片，参考电压 Vref=2.048V 时，失调误差为+3LSB，则在 ADC 输出全为 0 时，模拟输入电压值为?
- **A.** 1mV
- **B.** 4mV
- **C.** 2mV
- **D.** 6mV
- **答案**：D（存疑）
- **解析**：1LSB=2.048V/1024=2mV。失调误差+3LSB 表示输出码比理想值偏大 3 个码，按题库口径"输出全 0 对应的输入电压"=3LSB×2mV=6mV，选 D；失调误差的方向性定义存在歧义，标存疑。
- **标签**：测试测量｜模拟电路

### Q20. 增强型绝缘栅场效应管，当栅极 G 与源极 S 之间电压 Ugs<0（且 Ugs 电压不超器件规格）时，以下选项正确的是

### Q22. CPU 的处理流程可以抽象为哪三步?
- **A.** 读取(Fetch)=>执行(Execute)=>缓存(Cache)

### Q23. 判断数字信号所需传输带宽的标准为
- **A.** 信号能量最宽频率分布范围
- **B.** 信号幅度
- **C.** 信号上升下降时间
- **D.** 信号频率
- **答案**：C
- **解析**：数字信号带宽由边沿速度决定：BW≈0.35~0.5/Tr，上升/下降时间越快，频谱越高、所需传输带宽越大；与幅度和重复频率关系不大。
- **标签**：信号完整性

### Q24. 下列存储器中存取速度最快的是

- **D.** DDR
- **答案**：A

### Q25. 一个 8 位二进制整数用补码表示，由 4 个"1"和 4 个"0"组成，则
- **A.** 最小值为-16，最大值为 240
- **B.** 最小值为-121，最大值为 240
- **C.** 最小值为-16，最大值为 120
- **D.** 最小值为-121，最大值为 120
- **答案**：D
- **解析**：最大正数（符号位 0、含 4 个 1）：01111000=120；最小负数（符号位 1、含 4 个 1）：10000111，补码值为-121。故范围-121~120。
- **标签**：数字电路

### Q26. 关于 PCB 走线特征阻抗的说法错误的是
- **A.** 当到参考层距离变小时，特征阻抗变小
- **B.** 当介电常数变大时，特征阻抗变小
- **C.** 当走线变宽时，特征阻抗变大
- **答案**：C
- **解析**：走线变宽使单位长度电容增大，特征阻抗应变小而非变大，C 错误；A、B（距离变小、介电常数变大都使电容增大、阻抗减小）均正确。
- **标签**：信号完整性｜PCB设计

### Q28. 【多选】哪些会导致电阻类器件阻值变大
- **A.** 引脚断裂
- **B.** 电阻膜破损
- **C.** 银迁移
- **D.** 封装涂层开裂导致使用过程潮气入侵
- **答案**：BCD
- **解析**：电阻膜破损使导电路径变化、银迁移改变电阻体导电结构、潮气入侵使电阻材料性能退化，都会使阻值（通常变大）异常；引脚断裂是开路失效，不属于"阻值变大"，A 不选。

### Q29. OC 门电路(集电极开路、不含上拉电路)有哪些输出状态?
- **A.** 高电平
- **B.** 低电平
- **C.** 高阻
- **答案**：BC
- **解析**：无上拉的 OC 门输出管导通时输出低电平，截止时输出悬空呈高阻（需外部上拉才能输出高电平），故只有低电平与高阻两种状态。
- **标签**：数字电路

### Q30. 【多选】以下关于 PCB 散热设计说法正确的是

### Q31. 【多选】以下描述正确的有
- **A.** CML 主要用于超高速串行互连
- **B.** LVPECL 主要用于时钟，低抖动，低功耗

### Q32. 【多选】常见 SI 问题有哪些
- **A.** 回沟

### Q33. 【多选】传输线跨分割会产生什么影响
- **A.** 阻抗失配
- **B.** 容易产生串扰
- **C.** 容易产生 EMC 问题
- **D.** 回流路径增大
- **答案**：ABCD
- **解析**：跨分割使参考平面不连续，造成阻抗突变与反射（A）、回流路径绕行变长（D）、对邻近走线屏蔽减弱导致串扰增大（B）、回流环路增大引起辐射与抗扰度下降等 EMC 问题（C）。
- **标签**：信号完整性｜EMC电磁兼容

### Q34. 【多选】FPGA 或 CPLD 内使用相同时钟沿的同步数字电路，最高频率和哪些因素有关
- **A.** 时钟的占空比
- **B.** D 触发器之间最长的组合逻辑
- **C.** 时钟 skew
- **D.** 逻辑块间互连布线长度
- **答案**：BCD
- **解析**：同步电路最高频率 fmax=1/(Tcq+Tcomb+Tsu+Tskew)，取决于触发器间最长组合逻辑路径（B）、时钟偏斜（C）、互连布线延迟（D）；占空比不影响单沿同步电路的最高频率（A 不选）。
- **标签**：数字电路

### Q35. 【多选】如下对于晶体时钟电路布局的说法正确的是
- **A.** 走线尽量短而粗
- **B.** 晶体与 IC 布局在同一面
- **C.** 电感靠近晶体放置
- **D.** 高速信号尽量走差分走线
- **答案**：AB
- **解析**：晶体走线应短而粗以减小寄生与噪声耦合（A 对）；晶体与 MCU/IC 同面布置避免过孔换层引入寄生（B 对）；电感会产生磁场干扰，不应靠近晶体（C 错）；"高速信号走差分"与晶体布局无关（D 不选）。
- **标签**：PCB设计｜高频射频

### Q36. 【多选】下面关于 GPIO 描述错误的是()。
- **A.** GPIO 可以用于模拟 EEPROM 接口，对 EEPROM 存储器进行读写操作
- **B.** CPU 可以通过编程，决定 GPIO 输入、输出的通信功能，但不能是双向的
- **C.** GPIO 通常用于连接外部的 SDRAM，进行高速传输
- **D.** GPIO 可以由 CPU 编程决定方向，但不能查询其状态
- **答案**：BCD
- **解析**：GPIO 可软件模拟 I2C 等接口读写 EEPROM（A 对）；GPIO 可配置为输入/输出甚至双向，B 错；SDRAM 需专用存储控制器接口，GPIO 不能高速传输，C 错；GPIO 方向可编程且状态可读回，D 错。
- **标签**：数字电路｜其他

### Q37. 在组合逻辑电路中，有冒险一定存在竞争，有竞争也一定存在冒险。
- **A.** 正确
- **B.** 错误
- **答案**：B
- **解析**：竞争（两个信号经不同路径到达同一门）是产生冒险的必要条件：有冒险必有竞争；但存在竞争不一定产生冒险（只有当竞争导致输出出现毛刺时才形成冒险），故后半句错误，整题判错。
- **标签**：数字电路

### Q38. 计算机工作的最小时间单位是指令周期。
- **A.** 正确
- **B.** 错误
- **答案**：B
- **解析**：计算机最小时间单位是时钟周期（节拍脉冲）；指令周期包含若干机器周期，机器周期又由若干时钟周期组成。
- **标签**：其他

### Q39. LVDS 为低压差分信号，采用电流驱动模式，接收端需有 100 欧姆端接电阻，在接收方通过 100 欧电阻形成 350mV 电压摆幅，当电流正向流动时产生逻辑高电平，反之产生逻辑低电平。
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：LVDS 驱动器为约 3.5mA 电流源驱动，接收端 100Ω 端接电阻上形成约 350mV 差分摆幅；电流方向决定差分极性，从而区分逻辑高/低电平，描述正确。
- **标签**：信号完整性｜总线协议

### Q40. 路径延时通常容易受工艺、温度、长度等因素影响，所以在做时序分析时，需要考虑最大延时和最小延时。
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：PVT（工艺/电压/温度）偏差与布线长度使路径延时存在波动，时序分析必须做 max/min（setup/hold）双角分析，保证建立与保持时间在所有工艺角下都满足。
- **标签**：数字电路｜信号完整性
