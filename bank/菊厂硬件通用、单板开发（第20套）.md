# 菊厂硬件通用、单板开发（第20套，含第21套合并）

> 来源：菊厂 2021 校招笔试真题【通用硬件】（考试界面截图，2020-07-15 场次）。原第20套（Word 内嵌截图）与第21套（PDF 拍照件）为**同一场考试的两个版本，23 题完全相同**，已合并为一套。图中绿色选中项经工程校验修正，存疑题已标注。

### Q1. 下列不能用带使能端的二进制译码器实现的有（ ）
- **A.** 多路数据分配器
- **B.** 地址译码器
- **C.** 七段数字显示译码驱动
- **D.** 计数器
- **答案**：D
- **解析**：译码器是组合逻辑器件，可实现数据分配、地址译码、显示译码驱动；而计数器是时序逻辑电路，必须依赖时钟与存储状态，无法用纯组合的译码器实现。
- **标签**：数字电路

### Q2. 基于 IA64 架构的软件可以运行在 IA32 架构的处理器上。（ ）
- **A.** 正确
- **B.** 错误
- **答案**：B
- **解析**：IA64（Itanium）与 IA32（x86 32位）指令集架构不同，IA64 不向下兼容 IA32 指令（需靠软件模拟层），因此 IA64 软件不能直接运行在 IA32 处理器上。
- **标签**：其他｜微机原理

### Q3. N 型半导体的多子是自由电子，所以它带负电。（ ）
- **A.** 正确
- **B.** 错误
- **答案**：B
- **解析**：N 型半导体虽然多子为自由电子，但同时存在等量的正离子施主杂质与少子空穴，整体仍呈电中性。
- **标签**：元器件｜模拟电路

### Q4. 对板料进行多次拉伸时，为了消除形变强化，中途应进行（ ）
- **A.** 完全退火
- **B.** 再结晶退火
- **C.** 正火
- **答案**：B
- **解析**：拉深成形产生的加工硬化通过再结晶退火消除——加热至再结晶温度以上使变形晶粒重新结晶，恢复塑性以便继续拉深；完全退火主要用于亚共析钢铸锻件，正火不作消除冷变形强化之用。可确定，去掉存疑。
- **标签**：其他｜结构材料

### Q5. cache 的写策略一般包括 write back 和 write through 两种方式，前者减少了对内存的访问，所以性能更高。（ ）
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：write back（回写）只在缓存行被替换时才写回内存，减少内存访问次数，通常性能高于 write through；但一致性控制更复杂，说法总体成立。可确定，去掉存疑。
- **标签**：其他｜微机原理

### Q6. 模拟锁相环电路中，与鉴相参考信号 R 相连且与运放正输入相连的是（ ）
- **A.** UP 信号
- **B.** VCO 压控信号
- **C.** DOWN 信号
- **D.** 其他都可以
- **答案**：B（存疑，图中标注）
- **解析**：按原卷标注为 VCO 压控信号。PLL 中鉴相器比较参考信号与 VCO 反馈信号，环路滤波器运放输入接入反馈支路信号。
- **标签**：其他｜模拟电路

### Q7. 动态心电图机使用的 ECG 带宽是（ ）
- **A.** 0.05-40Hz
- **B.** 0.05-50Hz
- **C.** 0.05-150Hz
- **D.** 0.5-40Hz
- **答案**：A
- **解析**：动态（Holter）心电监护带宽典型为 0.05~40Hz（非诊断级监护带宽，符合 AAMI/IEC 对动态心电记录的要求），下限 0.05Hz 保证 ST 段基线稳定，上限 40Hz 保留 QRS 波主要能量；诊断级心电才需 0.05~100/150Hz。可确定，去掉存疑。
- **标签**：其他｜生物医学

### Q8. 计算机的字长是指（ ）
- **A.** 数据长度
- **B.** CPU 数据总线的宽度
- **C.** CPU 内部一次可处理的二进制位数
- **答案**：C
- **解析**：字长定义为 CPU 一次运算能处理的二进制位数，它与内部寄存器/运算单元宽度对应，与数据总线宽度可能不同（如 8088 字长 16 位、外部数据总线 8 位）。
- **标签**：其他｜微机原理

### Q9. 若 y(t)=f(t)*h(t)（卷积），则 f(2t)*h(2t) 等于（ ）
- **A.** y(2t)/4
- **B.** y(4t)/4
- **C.** y(2t)/2
- **D.** y(4t)/2
- **答案**：C
- **解析**：尺度变换性质：f(at)*h(at) = y(at)/|a|。取 a=2 得 y(2t)/2。
- **标签**：其他｜信号与系统

### Q10. 关于 PCB 层的设置，以下描述错误的是（ ）
- **A.** 器件面下面（第二层）优先设置为地平面
- **B.** 优先采用对称结构设计
- **C.** 尽量避免两个信号层直接相邻
- **D.** [?]（原文模糊，疑为"电源层与地层尽量远离"类表述）
- **答案**：D
- **校注**：原卷绿色选中第4项。经回看原图，该项以"在信号层…"开头，文字仍无法完全辨认；A/B/C均为正确的叠层设计原则（第2层完整地平面、叠层对称防翘曲、避免信号层直接相邻），故错误描述必为第4项，答案可确定为D，去掉存疑。
- **解析**：常规叠层原则：紧邻器件面的第2层设完整地平面、叠层对称防翘曲、避免两个信号层直接相邻（相邻信号层间应有参考平面）。
- **标签**：PCB设计｜信号完整性

### Q11. 考虑单板 12V 总线最低电压不低于 8V，如果 12V 输入上跌落最长 400us，负载最大电流 10A，则 12V 总线上电容最小为（ ）
- **A.** 1000uF
- **B.** 2500uF
- **C.** 5000uF
- **D.** 15000uF
- **答案**：A
- **解析**：C = I·Δt/ΔV = 10A × 400μs ÷ (12-8)V = 1000μF。
- **校注**：第20套版本（原卷截图）选项为 10000/2500/500/1500μF 且绿色标 10000μF。按公式精确计算 C=I·Δt/ΔV=1000μF；若按原卷选项作答，应取满足 ≥1000μF 的最小档 2500μF，原卷标 10000μF 疑为考生误选（或含可靠性余量设计考量）。本文件选项列表按 1000μF 精确值作答取 A。
- **标签**：电源设计

### Q12. 电源纹波噪声测试方式哪种更准确（ ）
- **A.** 无源探头+示波器设置为 50ohm DC 模式
- **B.** 无源探头+示波器设置为 1Mohm AC 模式
- **C.** 同轴线缆+10uF 电容隔直+示波器设置为 50ohm DC 模式
- **D.** 有源探头+示波器设置为 50ohm DC 模式
- **答案**：C
- **解析**：同轴线缆+隔直电容+50Ω 端接是纹波测量的标准做法：50Ω 匹配消除传输线反射（探头长地线会引入高频干扰），隔直电容防止大直流分量烧毁/饱和输入级，同轴屏蔽抑制空间噪声耦合。
- **标签**：测试测量｜电源设计

### Q13. 对于二进制信号传输来说，波特率在数值上等于比特率。（ ）
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：二进制（每个码元携带 1 bit 信息）时波特率（码元/秒）与比特率（bit/s）数值相等；多电平调制时不相等。
- **标签**：其他｜总线协议

### Q14. 数字电路设计中常采用地址的高位译码来产生芯片的片选（ ）
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：高位地址译码产生片选（区分不同器件的地址空间），低位地址直接接器件地址引脚（寻址片内单元），这是存储器/IO 映射的标准做法。
- **标签**：数字电路｜微机原理

### Q15. 温度升高，液体的表面张力一般将____（ ）
- **A.** 不变
- **B.** 增加
- **C.** 减小
- **D.** 不确定
- **答案**：C
- **解析**：液体表面张力随温度升高而减小（分子间作用力减弱，临界温度处趋于零）。
- **标签**：其他｜结构材料

### Q16. 正常情况下，脉冲的下降沿时间 TT 应在下述哪个条件下测量（ ）
- **A.** 在脉冲峰峰值的 10% 至 90% 处
- **B.** 在脉冲峰峰值的 0% 至 90% 处
- **C.** 在脉冲峰峰值的 10% 至 100% 处
- **D.** 在脉冲峰峰值的 90% 至 10% 处
- **答案**：D
- **解析**：下降时间定义为从高电平（90% Vpp）下降到低电平（10% Vpp）所需时间，方向由高到低；上升沿则相反（10%→90%）。
- **标签**：测试测量

### Q17. 疲劳破坏是由于裂纹扩展引起的（ ）
- **A.** 正确
- **B.** 错误
- **答案**：A
- **解析**：金属疲劳过程为：裂纹萌生→稳定扩展→最终快速断裂，疲劳破坏本质是循环载荷下裂纹萌生与扩展的结果。
- **标签**：其他｜结构材料

### Q18. 【多选】在数字逻辑电路设计中，要避免引起"竞争"现象，可以采用以下哪些方式（ ）
- **A.** 在电路中增加延迟逻辑
- **B.** 采用同步时序电路
- **C.** 采用异步时序电路
- **D.** 修改状态表赋值 [?]（原文模糊）
- **答案**：ABD
- **校注**：原卷仅第4项（"修改状态表赋值"，经回看原图确认）有绿色勾选。按理论判定：增加延迟逻辑（冗余项/选通脉冲）、采用同步时序电路、修改状态表赋值（改变状态编码相邻跳变路径）均可消除竞争冒险；异步时序电路恰恰更易产生竞争，C不可选。答案确定为ABD，去掉存疑。
- **解析**：消除竞争冒险的常用手段：加冗余项或滤波电容/引入选通脉冲（延迟逻辑）、改用同步时序设计、优化状态编码。
- **标签**：数字电路

### Q20. 【多选】关于 DMA 传输方式的说法，正确的有（ ）
- **A.** 需要 DMA 控制器参与数据传输
- **B.** 具有传输速度快、降低 CPU 负荷的优点
- **C.** 传输前后都不需要 CPU 参与
- **D.** 计算机系统的地址总线、数据总线、控制总线在 CPU 和 DMA 控制器之间复用
- **答案**：ABD
- **校注**：原卷绿色勾选为1、2、3（ABC）。C"传输前后都不需要CPU参与"错误——传输前需CPU初始化（源/目的地址、传输长度、控制字），传输结束后需CPU处理中断并做后处理；D"地址/数据/控制总线在CPU和DMA控制器之间（分时）复用"符合DMA系统总线共享的实际，为正确说法。修正为ABD。
- **解析**：DMA由DMA控制器作为总线主控接管系统总线完成数据搬运，速度快且减轻CPU负担，总线由CPU与DMAC经仲裁分时占用。
- **标签**：其他｜微机原理

### Q21. 在 Vgs 可用电压范围内，Vgs 越大，MOSFET 漏源导通电阻的变化是（ ）
- **A.** 变大
- **B.** 变小
- **C.** 不变
- **答案**：B
- **校注**：原卷标注为"不变"，疑为考生误选。Vgs 越大，沟道反型层电荷密度越大、沟道等效导通电阻越小，理论上可确定选B（Vgs 超出可用范围进入可靠性受限区另论），去掉存疑。
- **解析**：datasheet 的 Rds(on) 均在给定 Vgs（如 10V）下测试，Vgs 不足时 Rds(on) 显著增大、损耗加剧。
- **标签**：元器件｜电源设计

### Q22. 下面哪个电路属于组合逻辑电路（ ）
- **A.** 计数器
- **B.** 移位寄存器
- **C.** 译码器
- **D.** 触发器
- **答案**：C
- **解析**：译码器输出仅取决于当前输入，无记忆环节，是典型组合逻辑；计数器、移位寄存器、触发器均含存储状态，属时序逻辑。
- **标签**：数字电路

### Q23. 相啮合的标准齿轮，小轮的齿根厚度与大轮的齿根厚度相比（ ）
- **A.** 小轮齿根厚度大
- **B.** 大轮齿根厚度大
- **C.** 相等
- **答案**：B
- **解析**：标准直齿圆柱齿轮中齿数越少，齿根圆齿厚越薄（基圆越小、齿廓弯曲越厉害），故小齿轮齿根厚度较小——这也是小齿轮轮齿抗弯能力弱、通常需选较大模数或正变位的原因。理论上可确定，去掉存疑。
- **标签**：其他｜结构材料
