## 💡 为什么做这个

硬件校招笔试的备考痛点：

1. **真题散落各处**、无答案或答案错误百出；
2. **考试随机抽题**，覆盖面决定命中率，零散刷题效率低；
3. 网上资料**无法喂给 AI**——格式混乱，LLM 难以精确检索作答。

本仓库把 27 套真题整理为**结构化 Markdown**：每题统一格式（题干 / 选项 / 答案 / 解析 / 知识点标签），AI 可以直接 Grep 定位原题、精确作答；配套知识体系文档用于系统复习。

> 一句话：**把刷题变成数据工程。**

## 🚀 快速开始

### 1）给 AI 用（推荐）

把 `bank/` 目录喂给任何支持文件/Grep 的 AI（Claude Code、Cursor、Copilot 等）：

```text
# 让 AI 检索原题
在 bank/ 目录中搜索"扭环形计数器"，给出所有命中题目的答案与解析

# 让 AI 按标签抽题
把所有标签含「信号完整性」的题目列出来，做成练习清单

# 模拟考试
从 bank/ 随机抽 40 题（26 单选+10 多选+4 判断），考我，最后批改并讲解错题
```

题目格式统一，AI 解析零障碍：

```markdown
### Q12. 欲将电压信号转换成与之成比例的电流信号，应在放大电路中引入____。
- **A.** 电流并联负反馈
- **B.** 电压并联负反馈
- **C.** 电压串联负反馈
- **D.** 电流串联负反馈
- **答案**：D
- **解析**：V→I 转换要求输出电流稳定、不受负载变化影响，应引入电流串联负反馈……
- **标签**：模拟电路｜电源设计
```

### 2）给自己刷

直接打开 `bank/` 下任意一套（`第01套.md` ~ `第28套.md`），答案就在每题下方，配合 `knowledge/` 复盘错题对应的知识点。

## 📚 知识体系

[`knowledge/00-核心知识点总览.md`](./knowledge/00-核心知识点总览.md) 是教学首选入口：

- 十大主题核心结论 + 答题策略 + 6 类易错点清单（绝对化表述陷阱、方向性陷阱、固定计算套路……）
- 各分套摘要：每套高频考点与易错点归纳

## ✅ 质量保障

- **三道工序**：原文提取 → 结构化重建 → 逐题专业校验（模拟/数字/SI/PI/EMC/射频/测试多方向交叉复核）
- **纠错实录**：原流传版本中红点标注实为考生作答痕迹（抽验错误率约 1/4），已逐题按工程原理修正并保留校注；已知原库错误（趋肤效应、RC 时间常数、十六进制比较等）均已修正
- **存疑透明**：约 60 题标注 `（存疑）` 并附校注说明依据，绝不静默猜测
