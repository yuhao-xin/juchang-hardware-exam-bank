# 菊厂硬件通用、单板开发 第01-05套 知识点摘要（review-a）

本摘要归纳第01-05套共 165 道题（40+35+40+40+26，去除套间重复后）覆盖的核心知识点，按主题分组，供教学复习使用。

## 一、元器件（高频考点，占比最大）

**电容类（最高频）**
- 容值稳定性排序：NP0(Ⅰ类) > X7R/X5R(Ⅱ类稳定级) > Y5V(Ⅱ类可用级)；NP0 还以 ±30ppm/℃ 描述，X7R = -55~+125℃、±15%。
- 铝电解电容：非固体铝电容寿命瓶颈是**电解液挥发**（温度每升 10℃ 寿命减半）；低温下 ESR 增大、容量减小；漏电流比钽/瓷片大；电压降额按 80%（50% 是钽电容的要求）。
- 相同容值下，封装越大 ESL 越大、自谐振频率越低（1812 < 1210 < 0805 < 0603）。
- 有极性电容（铝电解、钽/固体铝电解）绝不能反接；薄膜、陶瓷无极性。
- 1 个大电容 vs 多个小电容并联：并联降 ESR 但"一定利于纹波抑制"是**错误**说法，须按目标阻抗-频率曲线设计 PDN。

**电阻类**
- 三位数字标注：105 = 10×10⁵ = 1MΩ。
- 温度系数：厚膜（最差）> 薄膜 > 金属箔（<5ppm/℃）。
- 电阻允许工作电压取 P=V²/R（额定功率电压）与最高使用电压的较小者（0.25W/100Ω → 5V）。

**二极管/三极管/MOS**
- PN 结正向压降负温度系数（-2mV/℃），温度升高压降变小；P 型硅多子为空穴（三价掺杂）。
- 肖特基管压降低（0.3~0.4V），适合低压大电流整流；二次击穿是从高压小电流向低压大电流的负阻跃变（热电击穿、不可逆）。
- 增强型 MOS 沟道掺杂与源漏相反、常闭；NMOS 的 Ron 小于同尺寸 PMOS。
- 稳压二极管用途：电压基准、过压保护、温度检测（利用温度系数）；**不能**用于电流采样。
- 晶振：Frequency Tolerance = 初始频差；负载电容 CL 越小实际振荡频率越**偏大**；CL 与驱动能力无关；负载能力用 CL 表征。

**电感/磁芯/磁珠**
- 电感饱和 → 磁导率下降 → 电感量/电抗**减小**；变压器饱和特性用**饱和电流**评估；感量 L=μN²Ae/le（增截面有效，加气隙减小）。
- 磁珠是**耗能**元件（非储能），高频呈高阻吸噪；额定电流降额 80% 使用；低频呈感性，滤波电路有谐振风险。
- 变压器损耗 = 磁滞 + 涡流 + 铜阻（集肤效应），无介电损耗。
- 机械应力敏感器件：BGA、MLCC 陶瓷电容。

**防护器件（EMC）**
- 响应速度（快→慢）：TVS(ps 级) > TSS > 压敏 MOV(ns 级) > 气体放电管(几十 ns)；通流能力排序相反（放电管最大）；TVS 失效多为短路、用于末级精细保护。

## 二、信号完整性（第二大主题）

- 反射根源是**阻抗不连续**（换层、跨分割、过孔、线宽变化、连接器）；反射系数：开路 +1、短路 -1、匹配 0。
- 始端串联匹配：R串 = Z0 - 驱动内阻（50-15≈33Ω）；串阻只能放**源端**；匹配方式有串阻/并联/戴维南/AC 四种。
- 边沿不单调（回沟/台阶）→ 错误采样、降低时序容限；回沟原因：未在末端测试、拓扑不佳、连接器阻抗不连续。
- 抖动不是匹配问题引起（源于噪声/串扰/地弹/电源纹波）。
- 微带线有效介电常数小 → 传播速度**快于**带状线；损耗与线长、频率、介电常数相关（温度次要）。
- tSU = 时钟沿**前**数据必须稳定的时间；沿后是保持时间；器件 tsu 可为负值。
- 行波（派生/分频）时钟存在累积偏斜，行波计数器不推荐；异常信号即使避开采样周期也不能直接忽略。

## 三、数字电路/总线

- I2C：SCL 高电平期间 SDA 由高到低为 START；多从器件靠地址区分；串阻与上拉取值取决于负载电容、上拉电压、速率、设备数。
- 同步计数器 CP 同步（与异步计数器的核心区别）；同步置数需时钟沿配合，异步清零立即生效；计数器累计 CP 脉冲。
- CPU 组成 = 运算器 + 控制器；中断在**指令执行完毕后**响应（"立即响应"的说法错）；DMA 请求优先于中断。
- TTL/CMOS 与 RS-232（±3~15V 负逻辑）互连必须电平转换（MAX3232）；噪声容限 ≥0.4V；ECL/PECL 高速但功耗大。
- 组合逻辑可实现译码器、选择器；分频器/计数器是时序逻辑；译码器输出有毛刺不能直接作时钟。
- LPDDR/DRAM 为 1T1C 结构存 1 bit；cache 对程序员透明。
- GPIO：负载端有上拉且默认使能时不能配置 PD；8 进制 4800 波特 → 14400 bit/s。

## 四、电源设计

- LDO 效率 = Vout/Vin（5V→3V 为 0.6）；功耗 = Imax×(Vin,max-Vout)，只降压、适合小压差小电流（5V→3.3V 1A 适用）。
- BUCK：电感越大纹波越小（但动态响应变慢）；输出质量受感值、封装、输入电容、工作模式影响。
- 功率晶体管低导通损耗需工作在**饱和区**；IGBT = 绝缘栅双极晶体管；晶闸管/二极管非全控器件。
- 光耦隔离驱动的优点：控制侧不承受主电路高压（但仍需隔离辅助电源）。
- 网口变压器：隔离、耦合、阻抗匹配、改善 EMI；PHY 中心抽头接法取决于电压驱动（接电源）还是电流驱动（电容接地）。

## 五、PCB / EMC / 测试测量

- PCB 布局：数模分区、强辐射器件远离边缘；钽电容**不**抗浪涌、不放电源前端；安规间距不考虑丝印。
- 跨分割 → 回流路径增大、阻抗失配、串扰、EMC；布线要求过孔少、线宽一致、无直角、回路面积小。
- 电过应力（EOS）= 过压/过流/过功率，机械应力不算；安规器件变更须认证报备；LPS 供电可豁免防火外壳。

## 六、测试测量

- 示波器+探头综合带宽：1/B²=1/B示²+1/B探²（1G+1G→0.71G）；在线测高速串行信号选高带宽高阻有源探头；有源探头输入电容小于无源探头。
- 捕捉毛刺用 Glitch 触发；数字万用表用双积分 ADC；采样频率须 >2 倍最高信号频率，否则混叠。
- 奈奎斯特：300~3400Hz 话音 → 8kHz 抽样。

## 七、控制基础

- 增加开环极点**降低**稳定性；相角裕度>0 且幅值裕度>1 = 稳定；特征方程系数全正只是必要条件（负系数必不稳定）。
- 调节时间体现快速性；负反馈需调整结构参数才能改善性能（不保证消除误差/稳定）。
- PLL 锁定标志是稳态相差为**固定小值**而非零。

## 易错点提醒（教学重点）

1. "一定/立即/必须"类绝对化表述多为错误选项（负反馈一定稳定、稳压管电流采样、行波计数器推荐使用、异常信号可忽略等）。
2. 概念易混：磁珠（耗能）vs 电感（储能）；Frequency Tolerance（初始偏差）vs Stability（稳定度）；调节时间（快速性）vs 稳态误差（准确性）。
3. 温度方向性：二极管压降随温升变小、铝电解 ESR 随**降温**增大、电解液挥发是寿命根源。
4. 排序类题高频出现：电容稳定性、防护器件响应速度/通流、电阻温度系数、滤波器工作频率（FBAR>SAW>陶瓷>晶体）。
5. 数值类：1eV=1.6×10⁻¹⁹J；105=1MΩ；8 进制波特率换算；综合带宽 0.71G。
