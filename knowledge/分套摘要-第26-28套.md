# 菊厂校招硬件真题（第26~28套）核心知识点摘要

本摘要覆盖第26套（合集：精选题+第12~24套，563题）、第27套（40题）、第28套（40题）共643题，按主题归纳高频考点、易错点与典型结论，供教学复习使用。

## 一、信号完整性（SI）与高速设计
- **反射与端接**：传输线特征阻抗 Z0 由介质介电常数与线宽/间距决定；源端串联端接（22~50Ω）用于吸收反射，并联端接到 Z0 用于长线匹配。信号上升时间 < 传播延迟的 2 倍即需视为传输线。
- **串扰**：相邻走线间距 ≥3W（3W 原则）可显著降低容性/感性耦合；关键信号线包地并多打过孔。
- **眼图与抖动**：眼图张开度反映码间干扰与噪声；随机抖动(RJ)与确定性抖动(DJ)需分开评估。
- **PCB 叠层**：高速信号紧邻完整参考平面（回流路径连续）；跨分割是 SI/EMC 共同大忌。阻抗控制典型值：单端 50Ω、差分 100Ω。
- **典型结论**：过孔存在寄生电感与电容，高速信号尽量少换层；Stub（残桩）会引起谐振，背钻可改善高频损耗。

## 二、电源设计与电源完整性（PI）
- **拓扑对比**：LDO 输出纹波小但效率低（压差大时发热严重）；Buck 效率高、纹波较大；Boost 只能升压且输入电流连续；反激适合隔离小功率。
- **Buck 关键公式**：电感纹波电流 ΔIL=(Ui−Uo)·D/(L·f)，提高开关频率可减小纹波和电感体积；临界连续时 ΔIL/2=Io。输出电容 ESR 决定纹波的主要成分之一。
- **去耦策略**：多容值组合（0.1μF+10μF+_bulk）覆盖宽频段；去耦电容靠近 IC 引脚放置；电源平面与地平面紧邻形成平面电容。
- **易错点**：提高输入电容不能减小电感纹波（只能抑制输入纹波）；BUCK 的 CC/D CM 模式判断看电感电流是否断续。

## 三、EMC 电磁兼容
- **三要素**：干扰源、耦合路径、敏感设备。屏蔽、滤波、接地是三大手段。
- **屏蔽**：孔缝泄漏是主要途径（缝隙长度 ≤ λ/20）；机壳搭接优先用导电衬垫（簧片/导电橡胶），阳极氧化铝面导电性差需处理。注意题库个别答案与工程惯例不一致处已标存疑。
- **滤波**：共模电感抑制共模干扰；Y 电容接机壳（漏电流限制）；电源端口用 π 型滤波。磁珠在高频呈阻性，适合抑制 EMI。
- **接地**：数字地与模拟地单点连接；机壳地/信号地/电源地分类管理；ESD 防护器件（TVS）靠近接口放置。
- **测试限值**：CISPR 25 / GB 9254 Class A（工业）vs Class B（民用，限值更严）；辐射发射测试 30MHz~1GHz 用环形天线扫描。

## 四、测试测量
- **示波器**：带宽 ≥ 3~5 倍被测信号最高频率分量（上升时间法 BW≥0.35/Tr）；探头 10:1 需补偿校准；测纹波用 20MHz 带宽限制+短接地弹簧。触发方式、探头地环路引入的振铃是常见考点。
- **万用表**：真有效值(Trms)测量非正弦信号；四线制(4W)测小电阻消除引线电阻。
- **频谱仪**：RBW 影响底噪与分辨率；驻波比(VSWR)≤1.5 为常见指标；网络分析仪测 S 参数（S11 回损、S21 插损）。
- **其他仪器**：逻辑分析仪多通道时序捕获；TDR 测阻抗与断点位置；ESD 枪接触放电 ±4kV/空气放电 ±8kV（常见等级）。

## 五、元器件特性
- **MOS 管与三极管**：NMOS 导通条件 Vgs>Vth；米勒平台出现在开关过渡区；三极管饱和条件 Ic<β·Ib。MOS 栅极电阻影响开关速度与振铃。
- **电容**：陶瓷电容 MLCC 有直流偏压容值衰减；X7R/X5R 温度特性优于 Y5V；电解电容低频特性好、高频需并联陶瓷电容。钽电容失效模式为短路起火。
- **电感**：饱和电流（感值下降）与温升电流两个指标均需满足；DC-DC 电感选型 ISAT≥1.3×峰值电流。
- **存储器**：DRAM 需刷新、SRAM 不需；Flash 写前擦除；DDR4 关键时序 tRCD/tRP/tCAS，ODT 改善信号完整性。

## 六、数字电路与总线协议
- **逻辑电平**：TTL/CMOS 电平兼容问题；开漏输出需上拉，可实现线与。
- **总线对比**：I2C 两线制（SDA/SCL，开漏+上拉，支持多从机寻址，速率 100k/400k/3.4M）；SPI 四线全双工（速率最高，无 ACK）；UART 异步（波特率一致即可，起始位/停止位）；RS232 ±12V 电平、RS485 差分长距离多点。
- **PCIe/USB**：PCIe 为串行差分 Lane（x1/x4/x8/x16，8b/10b/128b/130b 编码）；USB 2.0 差分对 90Ω 阻抗。

## 七、高频射频
- **传输线**：波导截止频率、同轴线 Z0=50Ω 标准；趋肤深度随频率升高而减小。
- **调制与指标**：AM/FM/QPSK/QAM 概念辨析；1dB 压缩点、三阶交调(IP3)是线性度核心指标；噪声系数级联公式（Friis：前级 NF 影响最大）。
- **匹配**：Smith 圆图用途；λ/4 阻抗变换器；驻波比与回波损耗换算（RL=20lg[(VSWR+1)/(VSWR−1)]）。

## 八、模拟电路
- **运放**：虚短虚断适用条件（负反馈）；带宽增益积(GBW)恒定；摆率限制大信号输出；比较器无负反馈不需补偿。
- **放大电路**：共射反相兼有电压增益；射随器阻抗变换；三组态增益/阻抗对比为高频考点。
- **滤波器**：巴特沃斯（平坦）、切比雪夫（陡峭有纹波）、贝塞尔（线性相位）；Sallen-Key 二阶拓扑。

## 复习建议
1. 优先掌握 SI/PI/EMC 三大主题的公式与设计规则（占分最重）；
2. 仪器使用注意"测量条件"类考点（带宽限制、探头选择、接地方式）；
3. 总线协议重点记结构差异与时序参数；
4. 遇到题库答案与工程原理冲突的题目，以标准教材结论为准，本文档已对个别存疑题（如电磁屏蔽材料、Buck 纹波参数）标注存疑并给出推导依据。
