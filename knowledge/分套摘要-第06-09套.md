# 第06-09套题库知识点摘要（review-b）

## 一、测试测量（高频考点，题量最大）

**核心概念：**
- 示波器带宽定义：正弦输入衰减到 70.7%（-3dB）处的频率；测量系统等效带宽 = 示波器与探头带宽的平方和倒数合成。
- 单端无源探头必须配 1MΩ 输入档位（探头补偿网络按此设计）；50Ω 档用于同轴电缆直连和高频有源探头匹配。
- 频率准确度 = (f−f0)/f0，单位 ppm（分母必须用标称值）。
- 采样定理：fs > 2·f_max 才不混叠；上升/下降时间统一定义在峰峰值 10%~90% 之间测量。
- 电源纹波测量最准确方式：同轴电缆 + 10µF 隔直电容 + 示波器 50Ω DC 档（菊厂规范做法）。
- 捕获毛刺用 Glitch 专用触发；逻辑分析仪擅长多通道逻辑组合/时序功能测试，示波器擅长边沿、抖动等模拟容限测试；差分信号必须用差分探头。
- 眼图：张开度看噪声/码间干扰，交叉点发散看抖动，幅度下降看衰减。

**易错点：** 探头档位选错导致失真；把脉宽（高电平持续时间）当作串扰/测量影响因素。

## 二、信号完整性与 PCB 设计

- 串扰影响因素：边沿陡峭（Tr/Tf）、驱动电流、信号层与参考平面间距；**脉宽不影响串扰**（高频考点）。
- 并联终端匹配特征：满幅沿线传输、反射被端接电阻吸收、接收端电压=发射端电压（对比：串联端接才是一半强度）。
- 叠层原则：器件面下第二层优先放地平面、避免两个信号层直接相邻、对称结构防翘曲、**电源层必须紧邻地平面**（"离底层越远越好"是典型错误选项）。
- 电容器真实模型 = C+ESL+ESR 串联，存在自谐振频率（SRF），高频去耦必须在 SRF 以下工作；容抗 Xc=1/(2πfC)。
- 电磁波在介质中传播速度比真空慢（v=1/√(με)，FR4 约光速一半）。

## 三、元器件

- 半导体：P/N 型半导体整体电中性（多子≠带电）；掺五价成 N 型、三价成 P 型；三极管是双极型、MOS 是单极型；硅管导通压降 0.6~0.7V > 锗管 0.2~0.3V。
- BJT 放大条件：发射结正偏、集电结反偏。
- 电容：工作电压须小于标称耐压（降额）；钽电容**有极性**；铝电解 ESR 随温度降低而增大（低温电解液电导率下降）。
- ENIG 镀层 Cu/Ni/Au 焊接时金层溶入焊料，实际由 Ni 层形成 IMC（金脆概念）。
- 电感：匝间短路因短路环去磁使感量大幅下降（低于按 N² 折算值）；功率电感四要素：电感量、饱和电流、温升电流、DCR。
- 存储器：DRAM 电容存储需刷新、上电内容随机；SRAM 触发器存储集成度低；Flash 非易失保持原数据；双极型工艺快但功耗大，ECL 速度最快。

## 四、电源设计

- Buck 降纹波手段：多相交错并联、提高开关频率、增大电感；**把陶瓷电容换成电解电容（ESR 大）反而增大纹波**。
- 掉电保持电容计算：C = I·Δt/ΔV（12V 跌到 8V、400µs、10A → 1000µF）。
- 齐纳稳压标准接法：限流电阻串联 + 稳压管与负载并联。
- ACF（有源钳位正激）利于自驱动同步整流；上电时序设计必须考虑软启动容差。
- 电源调压电阻精度常用 1%；安规电容放电测试只针对交流输入设备（X 电容跨 L-N、Y 电容跨 L/N-PE）。

## 五、数字电路与总线协议

- 组合逻辑 vs 时序逻辑：译码器/编码器/加法器是组合；计数器、移位寄存器、触发器是时序（高频考点）。
- 或非门一端接低电平当非门，与非门则接高电平；与非门输出低须全部输入为高；普通 TTL 推挽输出不能线与（须 OC/OD）。
- 8421 BCD 码逐位十进制读（10010111→97，勿当纯二进制 151）；正数原反补码相同；8 位 −1 补码 = 1111_1111；同或：相同为 1（0x5A⊕̄0xA5=0x00）。
- RS-232 负逻辑：+3~+15V 为逻辑 0，−3~−15V 为逻辑 1；帧校验为奇偶校验（只能检奇数位错）；每字符 10bit@2400bps→240 字符/秒。
- 二进制传输波特率=比特率（多进制时比特率=波特率×log₂M）；片选由高位地址译码产生；PCI 为 32/64 位复用总线（"16 位"是错误选项）；中继器-物理层、交换机-链路层、路由器-网络层；192.168.0.1 为 C 类私有地址。
- 奇偶校验、OSI 分层（应用层下是表示层）、DMA（总线权切换、CPU 仅参与首尾）、物理层只管电气/机械特性。

## 六、其他与工程常识

- 数字化流程：采样→量化→编码；LTI 稳定系统极点在 S 左半平面；零状态响应=激励卷积单位冲激响应；卷积尺度特性 f(2t)*h(2t)=y(2t)/2。
- 三角波积分得正弦波；比较器运放工作在开环/正反馈，运算电路靠深度负反馈进入线性区；放大电路非线性失真源于晶体管非线性。
- 8086：EU+BIU 两大单元、复位入口 FFFF0H（硬件决定）、16 位地址线寻 64K I/O 端口、20 位寻 1M 存储、I/O 端口地址放 DX。
- 激光四大特性：高亮度、方向性、单色性、相干性好；光纤通信用 850/1310/1550nm 红外窗口；动态心电 ECG 带宽 0.5~40Hz（诊断型 0.05~150Hz）。
- 机械/材料：小齿轮齿根薄、最先损坏；疲劳破坏=裂纹扩展；多次拉伸中途再结晶退火消除加工硬化；温度升高表面张力减小；亲水（θ<90°）时粗糙度越大越易润湿；同轴度属定位公差。
- 安全常识：三孔插座是保护接地（不接地电器照样能工作）；示波器安全操作三要素（静电手环、识别危险、可靠接地）。

## 七、易错点汇总（教学提示）

1. "半导体带电性"、"线与条件"、"奇偶校验位数"是概念性陷阱，答案几乎都偏"否定"。
2. 计算题套路固定：电容放电 C=IΔt/ΔV、DAC 分辨率×码值、串口字符数、8421 码、补码转换，务必动手算而不是凭感觉。
3. 菊厂规范类题目（纹波测量方式、PCB 叠层、调压电阻精度）有企业标准答案倾向，选"同轴线缆+50Ω DC"、"第二层放地"等规范表述。
4. 本批共 142 题，存疑 4 题：06 套 Q8（ACF 拓扑出处罕见）、07 套 Q39（调压电阻精度）、08/09 套 Q20（PLL 题干表述不清）、08/09 套 Q31（竞争消除方法选项组合）。
