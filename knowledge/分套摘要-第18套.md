# 分套摘要 - 第18套（菊厂硬件通用、单板开发）

本套共 42 题（判断题 14 道、单选 22 道、多选 3 道，原卷编号跳号/重号已重排），覆盖面广，以基础概念判断为主。

**数字与存储**：SRAM（触发器存储、无需刷新）与 DRAM（电容存储、需周期刷新）的区别是常考点；D 触发器建立/保持时间定义；补码运算；译码器属组合逻辑而计数器/移位寄存器/触发器属时序逻辑；带使能译码器可实现数据分配器、地址译码但不能实现计数器；Cache 写策略中 write back 减少内存访问故性能更高；8086 内部由 EU 与 BIU 构成；高位地址译码产生片选。

**模拟与器件**：硅管导通压降（0.6~0.7V）大于锗管（0.2~0.3V）；N 型半导体掺五价元素且整体电中性；放大器非线性失真源于晶体管非线性；抑制 50Hz 工频干扰用带阻（陷波）滤波器；A/D 转换流程为采样→量化→编码；卷积尺度特性 f(at)*h(at)=(1/a)y(at)；平行板电容器断电后插入金属板（间距减小），电压按 Q 不变减小为 2U/3。

**电源与测量**：Buck 减纹波手段（多相并联、提频、加电感），换电解电容（ESR 大）无效；负载电容估算 C=I·t/ΔV（本套算得 1000uF）；纹波测量首选同轴线+10uF 隔直+50ohm DC 挡；脉冲下降时间按 90%~10% 峰峰值定义；动态心电图 ECG 带宽按 AAMI EC38 为 0.05~40Hz。

**PCB/SI 与系统**：叠层设计中电源层应紧邻地平面而非远离；眼图可分析码间干扰、抖动、噪声与衰减；交换机隔离冲突域，中继器/交换机/路由器分属物理层/链路层/网络层；RS232 用奇偶校验；PCI 为 32/64 位、地址数据复用、即插即用；DMA 传输前后仍需 CPU 参与初始化与结束处理；MOSFET 的 Rds(on) 随 Vgs 增大而减小。

**机械/材料杂项**：齿轮小齿轮齿根厚小于大齿轮易损坏；多次拉深中途需再结晶退火消除加工硬化；熔体表面张力随温度升高而减小；疲劳破坏由裂纹扩展引起；IA-64 不兼容 IA-32。

存疑题：Q28（锁相环信号连接，原卷未定）、Q40（竞争避免措施 ABD，推断答案）。
