# 菊厂硬件通用/单板开发笔试 —— 核心知识点总览（教学用）

> 依据 27 套真题（约 1530 题）逐题提炼，按考试权重排序。配合《手册精华-菊厂硬件工程师手册.md》和各分套摘要使用。

## 〇、考试结构画像

- **题量与题型**：每套 40 题左右（26 单选 + 10 多选 + 4 判断），考试随机抽题，新旧卷混合——刷题覆盖率决定命中率。
- **权重排序**（按真题出现密度）：①信号完整性/SI ②电源设计/PI ③元器件特性 ④数字电路与总线协议 ⑤测试测量 ⑥EMC电磁兼容 ⑦模拟电路 ⑧高频射频 ⑨微机原理与杂项（材料/机械/光学，每卷约 2-4 题）。

## 一、信号完整性（第一高频考区）

**特征阻抗**
- 由横截面结构（线宽、铜厚、到参考层距离）与介质 Dk 决定；**与线长无关**（最高频陷阱题）。
- 走线变宽 / Dk 变大 / 离参考层变近 → 阻抗变小。典型控制值：单端 50Ω、差分 100Ω、USB2.0 90Ω。

**反射与匹配**
- 反射根源 = 阻抗不连续（换层、过孔、跨分割、线宽变化、连接器）。
- 反射系数：匹配 0、开路 **+1**、短路 −1。
- 匹配四法：源端串联（波形半强度、点对点）、终端并联（满强度、功耗大）、戴维南（可提供偏置）、AC（静态功耗最低）。串阻 R = Z0 − 驱动内阻（≈22-33Ω）。

**串扰**
- 影响因素：边沿速率 Tr/Tf（越快越大）、驱动电流、线距、并行长度、离参考层距离；**与高电平持续时间（脉宽）无关**（高频陷阱）。
- 减小手段：3W 原则、包地、放缓边沿、贴近平面；**拉开信号层与参考层间距反而加重串扰**。
- 近端串扰（NEXT）容性感性同向叠加，远端（FEXT）反向抵消。

**高速设计**
- 长线判据：Tr < 2×传播延迟（或线长 > 17cm/数字信号 BW≈0.35/Tr~0.4/Tr）。
- 过孔 stub 引起谐振 → 背钻/盲孔解决；换层处加回流旁路电容；严禁跨分割。
- 抖动是时间偏差（非幅值）；眼图张开度=噪声/码间干扰，交叉点发散=抖动。
- LVDS：电流驱动、100Ω 端接、350mV 摆幅；LVPECL 用于时钟；CML 超高速。差分回流主要在参考平面。

## 二、电源设计

**LDO（线性电源）**
- 结构 = 基准 + 误差放大器 + 调整管，**无电感**；效率 η≈Vout/Vin；功耗 = (Vin−Vout)×Iout；只适合低压差小电流。
- 输出电容 ESR 不是越低越好（环路稳定区间）；压差必须 > dropout。

**Buck/DCDC**
- Vout = Vin·D；纹波电流 ΔIL = (Uin−Uo)·D/(L·f)：加大电感、提高频率 → 纹波减小（但动态响应变慢）。
- 临界连续 Io = ΔIL/2；降纹波：多相交错、升频、加大电感；**电解电容换陶瓷可减纹波，反之增大**。
- 掉电保持电容：C = I·Δt/ΔV（经典题：12V→8V、400µs、10A → 1000µF）。

**PDN/去耦**
- 目标阻抗设计；超标对策 = 降 ESR（大平面）/ 降 ESL（缩短回路）/ 超标频点加电容。
- 电容真实模型 C+ESR+ESL，存在自谐振频率 SRF；容值越大 SRF 越低——大电容管低频、小电容管高频；同容值封装越大 ESL 越大。
- 陶瓷电容三大衰减：DC 偏压（容值变小）、温度、老化；MLCC 对机械应力敏感。

## 三、元器件

**电容**
- 稳定性排序：NP0 > X7R/X5R > Y5V；容值标注 105 = 10×10⁵。
- 铝电解：寿命瓶颈=电解液挥发（每升 10℃ 寿命减半）；低温 ESR 增大容量减小；降额 80%。
- 钽电容：有极性、失效模式短路起火、不抗浪涌、不放电源前端。

**电阻/电感/磁珠**
- 温度系数：厚膜 > 薄膜 > 金属箔；允许工作电压取 min(额定功率电压, 最高使用电压)。
- 电感饱和 → μ 下降 → 电感量/电抗**减小**；功率电感四要素：L、Isat、温升电流、DCR。
- **磁珠是耗能元件**（高频呈阻性吸噪），电感是储能元件——概念辨析高频题。

**二极管/三极管/MOS**
- PN 结压降负温度系数（−2mV/℃）；肖特基压降 0.3-0.4V 适合低压整流。
- 三极管饱和 = 发射结、集电结双正偏；共基电流增益≈1 最小，共射电压/功率增益最高。
- MOS：增强型 Vgs=0 无沟道；Vgs 越大 Rds(on) 越小；同尺寸 NMOS Ron < PMOS；gm ∝ √ID。
- 防护器件响应速度：TVS(ps) > TSS > MOV(ns) > 气体放电管；通流能力相反。

## 四、数字电路与总线

- **组合 vs 时序**：译码器/编码器/加法器=组合；计数器/移位寄存器/触发器=时序（每卷必考）。
- **OC/OD 门**：实现**线与**（不是线或）+ 电平转换；推挽输出不能线与；CMOS 未用引脚必须上下拉。
- **扭环形（约翰逊）计数器**模值 2n；74LS161 反馈清零/置数构 N 进制。
- **异步 FIFO**：满信号由写时钟域产生、空信号由读时钟域产生。
- 亚稳态：同步器/快触发器/陡边沿解决；提高时钟频率反而加重。
- **I2C**：Start=SCL 高时 SDA 高→低；Stop=SCL 高时 SDA 低→高；半双工、地址寻址、总线电容上限 400pF。
- **SPI**：4 线全双工、CS 低有效、一主多从；MOSI=主出从入。
- **RS-232**：**负逻辑**（"1"=−3~−15V）；UART 异步；RS485/LVDS 差分。
- **哈佛结构**=程序/数据分开存储；冯·诺依曼=共享（易考"说反"）。
- CPU 组成=运算器+控制器；**中断在指令执行完毕后响应**（"立即响应"是错误选项）；DMA 传输前后 CPU 仍需参与（初始化+中断处理），总线在 CPU 与 DMAC 间分时复用。
- 存储层次：Cache(SRAM) > DDR > Flash > HDD；**DRAM 需刷新**；流水线并非越深越好（跨套反复考）。

## 五、测试测量

- 示波器带宽 = −3dB（70.7%）点；系统带宽合成 1/B²=1/B₁²+1/B₂²；选 ≥3~5 倍被测信号频率（或 BW≥0.35/Tr）。
- 无源探头配 1MΩ 档；50Ω 档用于同轴直连/高频有源探头；**测高速信号禁长地线**；USB 差分信号用差分探头；测 32kHz 晶振用低容（0.1pF）探头。
- **电源纹波测量**（菊厂规范，反复考）：同轴线缆 + 10µF 隔直 + 50Ω DC 档；或 AC 耦合 + 20MHz 带宽限制 + 短接地弹簧；测噪声才用全带宽。
- 上升/下降时间在峰峰值 10%~90% 测量（下降沿 90%→10%）；采样定理 fs > 2fmax；网分误差三类中**随机误差不可校准**。
- Y 因子 = 10^((P_hot−P_cold)/10)；8 位 ADC 分辨率 = Vref/2ⁿ。

## 六、EMC 电磁兼容

- **三要素**：骚扰源、耦合路径、敏感设备；三板斧：屏蔽、滤波、接地。
- 屏蔽：孔缝泄漏为主，缝隙 ≤ λ/20；100kHz 时钟陡边沿谐波可辐射到百 MHz 以上。
- 接地：数字地/模拟地单点连接；300kHz 以下单点、以上多点；机壳地/信号地/电源地分类。
- 滤波：共模电感抑制共模；π 型滤波 10µH+10µF+0.1µF；Y 电容接机壳（漏电流限制）。
- 磁珠高频受限主因 = 涡流损耗增大。

## 七、高频射频

- TEM 波需两导体以上——矩形波导（单导体）只能传 TE/TM。
- 1dB 压缩点与 IP3 是两回事；衰减器 NF = 插损；级联 NF 用 Friis 公式（前级主导）。
- 谐振回路 Q 越大越尖锐、选择性越好、**带宽越窄**；理想 LC 串联谐振阻抗 0、并联 ∞。
- 光纤通信窗口 850/1310/1550nm；滤波器：巴特沃斯平坦、切比雪夫陡峭、贝塞尔线性相位。

## 八、模拟电路

- 理想运放四条件：Aod→∞、Rid→∞、**Ro→0**（"输出电阻无穷大"是陷阱）、KCMR→∞；虚短虚断仅适用负反馈。
- 失调电流 = 两输入端**静态电流之差**；失调电压 = 使输出为零所需输入补偿电压。
- V→I 转换 = **电流串联**负反馈；输出稳流、抗源阻干扰也用串联电流负反馈。
- 比较器工作在开环/正反馈，无负反馈；运放线性区靠深度负反馈。
- 三种组态速记：共射增益最高、共集阻抗变换（输入大输出小）、共基带宽最宽。

## 九、微机原理与工程杂项

- 8086：EU+BIU；复位入口 FFFF0H；20 位地址寻 1M；I/O 地址放 DX。
- 字长 = CPU 一次可处理的位数（不是数据总线宽度）；32 位 CPU 看内部数据通路。
- 材料/机械：多次拉伸中途再结晶退火；疲劳破坏=裂纹扩展；小齿轮齿根薄先损坏；温度升表面张力减小。
- 动态心电 ECG 带宽 0.05~40Hz；激光四特性；三孔插座=保护接地。

## 十、答题策略与易错点（教学重点）

1. **绝对化表述多为错误选项**："一定""立即""必须""越…越好"——负反馈一定稳定、ESR 越低越好、PDN 阻抗越低越好、异常信号可忽略。
2. **方向性陷阱**：电感饱和电抗减小；Tco 增大→建立裕量变小；拉开层间距加重串扰；升高频率→纹波减小/EMI 恶化（按对象辨析）。
3. **计算题套路固定**（务必动手算）：C=IΔt/ΔV、ADC 分辨率 Vref/2ⁿ、串口字符数、8421 码逐位读、补码、波特率换算、Y 因子。
4. **概念易混清单**：磁珠 vs 电感；线与 vs 线或；竞争 vs 冒险（有竞争未必有冒险）；IP3 vs 1dB 压缩点；Frequency Tolerance vs Stability；系统/随机/漂移误差。
5. **菊厂规范倾向题**：纹波测量（同轴+隔直+50Ω）、PCB 叠层（第二层放地、对称、信号层不相邻）、调压电阻 1% 精度——选规范表述。
6. 原题库少量官方答案有误（趋肤效应、RC 时间常数、0xBB、PLC/QLC 密度等），本题库已修正并标"存疑"——**以标准教材结论为准**。
